# v0.7.7 変更範囲監査

更新日: 2026-09-25。基点は `origin/main` の `30011399`、監査対象は `feat/v0.7.7-landscape-ui` の `35973a71` までとする。

## 監査結果

- コミット済み差分は168ファイル、4,286行追加、1,247行削除。
- FreeInk SDKはPR #99を含む `bc31e96`。QMI8658の約117 Hz化、little-endian読み取り、0x6A／0x6B検出を含む。
- X4の電源ラッチ修正と電源診断ログは、複数回の実機比較後に `35973a71` で正式採用した。
- 未追跡の `fs_/` はシミュレーター／実機用データであり、リリースコミットへ含めない。
- FreeInk SDK PR #104のディープスリープ失敗時復旧は、現在のsubmodule revisionに含まれない。`bc31e96`からPR #104のコミットへ進めるとX4/X4C表示、IMU軸補正、SD更新リカバリー、端末検出も同時に変わるため、再現していない稀な復旧経路のためにv0.7.7の確認範囲を広げない。次回SDK更新時の候補として保留する。
- 実機確認と採否決定後、バージョン番号をv0.7.7へ更新した。
