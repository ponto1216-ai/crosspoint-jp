# 本体と操作の設定

[マニュアルの目次](manual-ja.md)

## 設定画面

ホームから **設定** を開くと、上部でカテゴリ、下部で項目を選びます。

| カテゴリ | 主な内容 |
|---|---|
| 表示 | テーマ、画面表示、スリープ画面 |
| 読書 | 横書き・縦書きの表示、フォント、書籍スタイル、読書設定プロファイル、フォントのダウンロード |
| 操作 | ボタン割り当て、ページ送りなどの操作 |
| 本体 | Wi-Fi、SDカード、読書キャッシュ、診断、更新、端末情報 |

X3のRTC関連項目は **本体** に表示されます。RTCを有効にすると関連する項目が表示されます。端末によって表示される項目が異なります。

### 変更と保存

1. 画面に表示された **上**／**下** でカテゴリを選びます。
2. **左**／**右** で項目を選びます。カテゴリ名を選んでいるときに **決定** を押すと、次のカテゴリに切り替わります。
3. 値を変更できる項目は **決定** で編集し、**左**／**右** で値を変えます。
4. **決定** または **戻る** で編集を終えます。

設定は変更時に反映され、設定画面を閉じると保存されます。ボタンの割り当てが分からなくなったときは、画面下部の表示に従い、**操作** カテゴリで割り当てを確認してください。

## 表示・スリープ・ボタン

**表示** でテーマやスリープ画面を、**操作** でボタンの割り当てやページ送り動作を調整します。変更した後は本を開き、ページ送りとスリープ・復帰を確認してください。

### スリープ画面の種類

**設定 → 表示 → スリープ画面** では、スリープ中に電子ペーパーへ残す画面を選べます。

| 設定値 | 表示内容 |
|---|---|
| **ダーク** | 暗い背景にYomukaのロゴを表示します。 |
| **ライト** | 明るい背景にYomukaのロゴを表示します。 |
| **カスタム** | SDカードのスリープ画像から1枚を表示します。画像が見つからない場合はダークになります。 |
| **カバー** | 最後に開いたEPUB・XTC・TXTの表紙を表示します。表紙を取得できない場合はダークになります。 |
| **なし** | 何も描かない白い画面にします。 |
| **カバー+カスタム** | 読書画面からスリープした場合は表紙、それ以外はカスタム画像を表示します。 |
| **透過オーバーレイ** | 現在の画面を残し、その上へ専用BMPを重ねます。画像が見つからない場合は通常のダーク画面になります。 |

**スリープ画面カバーモード** は、表紙と通常のカスタム画像の配置に使われます。**フィット** は画像全体を画面内へ収め、**クロップ** は画面を埋めるように端を切り抜きます。**スリープ画面カバーフィルター** では、階調表示、白黒コントラスト、白黒反転を選べます。画面上の **上下反転** は、この項目では画像の上下方向ではなく白黒の反転を表します。

### カスタム画像をSDカードへ置く

複数の画像を使う場合は、SDカードの一番上に`.sleep`フォルダを作り、その中へBMPファイルを置きます。`.sleep`がなければ`sleep`フォルダも使用できます。有効な画像から毎回1枚が選ばれ、最近表示した画像が続くことをできるだけ避けます。

```text
SDカード
└─ .sleep
   ├─ scene01.bmp
   ├─ scene02.bmp
   └─ scene03.bmp
```

フォルダに有効なBMPがない場合は、SDカード直下の`sleep.bmp`を使用します。優先順位は`.sleep`フォルダ、`sleep`フォルダ、`sleep.bmp`の順です。`.sleep`のように名前が`.`で始まるフォルダを端末のファイル一覧に表示するには、**設定 → 本体 → 隠しファイルを表示** を有効にします。

通常のカスタム画像には、無圧縮の24bit BMPを推奨します。画面に合わせて用意する場合の縦向き解像度は、X4が480×800、X3が528×792です。横長の画像も表示時に中央配置・縮小または切り抜きされます。

### 透過オーバーレイ画像を置く

透過オーバーレイは通常のカスタム画像と保存場所が異なります。単一画像はSDカード直下の`sleep-overlay.bmp`、複数画像は`/.sleep-overlay/`へ置きます。単一画像がある場合はフォルダより優先されます。

```text
SDカード
├─ sleep-overlay.bmp
└─ .sleep-overlay
   ├─ frame01.bmp
   └─ frame02.bmp
```

通常のBMPでは白い部分を透過として扱います。画素ごとの透明度を使う場合は、アルファ情報を含む無圧縮32bit BGRA BMPを使用します。画像は画面より大きくできません。透過PNGには対応していません。

### Web画面からスリープ画像を追加する

端末の **ファイル転送** を開始してブラウザで端末を開き、上部の **Sleep** を選びます。

通常のスリープ画像はJPEG、PNG、BMPを選択できます。位置、拡大率、明るさ、コントラストを調整してアップロードすると、端末の解像度に合わせた24bit BMPへ変換され、`/.sleep/`へ保存されます。**Saved Sleep Images** には`/.sleep/`内の画像が表示され、サムネイルを確認して削除できます。

**Transparent BMP Overlays** では、BMPを変換せずに`/.sleep-overlay/`へ保存します。32bit BGRA BMPなら画素ごとの透明度を保てます。通常のBMPは白を透明として扱います。端末側で **設定 → 表示 → スリープ画面 → 透過オーバーレイ** を選んで使用してください。`/.sleep-overlay/`内の画像もWeb画面で一覧・削除できます。

Web画面では新しい標準フォルダの`/.sleep/`と`/.sleep-overlay/`だけを管理します。旧形式の`/sleep/`、`/sleep.bmp`、`/sleep-overlay.bmp`は削除や移動をせず、端末側では引き続き互換形式として読み込まれます。接続方法は[Wi-Fiとファイル転送](wifi-transfer-ja.md)を参照してください。

### X3のRTCとカレンダー

X3では **設定 → 本体 → RTC有効（電池消費大）** を有効にすると、スリープ画面カレンダーと配置を設定できます。正しい日付が設定されている場合だけ表示されます。透過オーバーレイを正常に表示した場合、カレンダーは重ねません。X4には外付けRTCがないため、これらの項目は表示されません。

**設定 → 操作 → 電源ボタン短押し** では短押しをスリープに割り当てられます。自動スリープまでの時間は **設定 → 本体 → スリープまでの時間** で変更します。画像の追加や設定変更後は一度スリープし、表示と復帰位置を確認してください。

## 言語とフォント

**設定 → 本体 → 言語** から表示言語を選べます。メニューに使うUIフォントと、本文に使うSDカードフォントは別です。本文のフォントを追加する操作は[フォントの導入](cjk-fonts.md)を参照してください。

## 全体のキャッシュ操作・診断・更新

**本体** には全体の読書キャッシュ消去・生成があります。1冊の問題を調べる場合は、まず[読書中メニューの書籍単位の操作](reading-ja.md#読書キャッシュ)を使ってください。

[診断レポートの保存](reporting-bugs-ja.md)と[ファームウェア更新](firmware-update-ja.md)は専用ページで手順を説明しています。

## 設定のバックアップ

**設定 → 本体 → 設定バックアップ** から **SDカードへ保存** または **設定バックアップを復元** を選びます。復元時は確認画面を読み、完了後にYomukaを再起動してください。読書表示だけを試して戻したい場合は[読書設定プロファイル](reading-settings-ja.md#読書設定プロファイル)を使えます。
