# Wi-Fiとファイル転送

[マニュアルの目次](manual-ja.md)

## PC・スマートフォンから本を転送する

1. ホームの **ファイル転送 → ネットワークに参加** を開き、画面の案内に従ってWi-Fiへ接続します。2.4GHzのネットワークを使います。
2. PCまたはスマートフォンも同じネットワークへ接続します。
3. 端末に表示されたIPアドレスをブラウザで開きます。例えば `http://192.168.1.102/` です。
4. ファイル管理画面で転送先フォルダを開き、アップロードから本を選びます。
5. 転送の完了を確認してから端末側で **戻る** を選び、転送画面を終了します。

端末の転送画面を終了するとWebサーバーは停止します。転送が終わるまでSDカードを抜かないでください。

## 本を整理する

Webのファイル管理ではフォルダの作成、本の移動・改名・削除を行えます。削除する前に対象を確認し、必要な本はPCへ保存してください。本の履歴や書庫の操作は[本の管理](library-ja.md)を参照してください。

## スリープ画像を追加する

Web画面上部の **Sleep** では、JPEG・PNG・BMPを画面サイズに合わせて切り抜き、スリープ画面用のBMPとして`/.sleep/`へ保存できます。**Saved Sleep Images** で保存済み画像を確認・削除できます。端末側で **設定 → 表示 → スリープ画面 → カスタム** を選んで使用します。

透過用には **Transparent BMP Overlays** からBMPを変換せず`/.sleep-overlay/`へ送れます。端末側で **設定 → 表示 → スリープ画面 → 透過オーバーレイ** を選びます。32bit BGRA BMPの透明度は保持され、通常のBMPでは白い部分が透明になります。透過PNGはまだ扱えません。SDカードのフォルダ構成、画像の優先順位、旧形式との互換性は[スリープ画面の説明](device-settings-ja.md#スリープ画面の種類)を参照してください。

## 青空文庫とCalibre

青空文庫は端末の青空文庫画面から作品を探してダウンロードできます。取得後は一覧から開いて読めます。作品の利用条件は配布元の案内に従ってください。

Calibreから転送する場合は、[CrossPoint Reader用プラグインの配布元](https://github.com/crosspoint-reader/calibre-plugins/releases)の案内に従ってプラグインを導入し、端末で **ファイル転送 → Calibreワイヤレス** を選びます。PCと端末を同じネットワークにつないでからCalibreで送信します。

## ルーターを使わずに接続する

**ファイル転送 → ホットスポットを作成** を選ぶと、端末自身がWi-Fiの接続先になります。PC・スマートフォンを端末に表示されたネットワークへ接続し、表示されたアドレスをブラウザで開いてください。転送後は元のネットワークへ戻します。

## ネットワークの注意

転送用Web画面には同じネットワークの端末からアクセスできます。認証のないHTTPで動作するため、信頼できるネットワークで使用し、作業が終わったら転送画面を閉じてください。保存されたWi-Fi情報やSDカード全体を不具合報告へ添付しないでください。

接続できない場合は[困ったとき](troubleshooting-ja.md#wi-fiファイル転送が使えない)へ。プログラムから操作する開発者向けの仕様は[Web API](development/webserver-endpoints.md)を参照してください。
