# 基本操作・設定・不具合の確認

このページは、CrossPoint Yomuka v0.7.2 の日常的な操作、設定の場所、不具合を安全に切り分けるための手順をまとめたものです。

端末のボタン割り当てや画面の向きによって物理ボタンの役割は変わります。常に、画面下部に表示される操作名（戻る、決定、前、次など）を基準にしてください。

## スリープと再起動

- 電源ボタンの長押しでスリープに入ります。短押しの動作は設定で変えられる場合があります。
- 画面が固まった、またはフォントやSDカードの変更を反映したい場合は、側面の **Reset** を一度押してから **Power** を数秒長押しし、起動画面が出るまで待ちます。
- 再起動でSDカード上の書籍は消えません。通常は最後に読んでいた書籍を開けます。

> [!CAUTION]
> ファームウェア更新中、フォントのダウンロード中、SDカードへの書き込み中、または読書キャッシュ生成中には、Resetを押したりSDカードを抜いたりしないでください。

## 設定画面

ホームから **設定** を開くと、上部でカテゴリ、下部で項目を選びます。

| カテゴリ | 主な内容 |
|---|---|
| 表示 | テーマ、画面表示、スリープ画面 |
| 読書 | 横書き・縦書きの表示、フォント、書籍スタイル、読書キャッシュ、フォントのダウンロード |
| 操作 | ボタン割り当て、ページ送りなどの操作 |
| 本体 | Wi-Fi、SDカード、診断、更新、端末情報 |

X3では、RTCに関する項目が **RTC設定** カテゴリに追加されます。項目や並びは端末・ファームウェアにより少し異なることがあります。

### 変更と保存

1. 画面に表示された **上**／**下** でカテゴリを選びます。
2. **決定** または画面に表示された移動操作で項目へ進みます。
3. 値を変更できる項目は **決定** で編集し、**左**／**右** で値を変えます。
4. **決定** または **戻る** で編集を終えます。

設定は変更時に反映され、設定画面を閉じると保存されます。ボタンの割り当てが分からなくなったときは、画面下部の表示に従い、**操作** カテゴリで割り当てを確認してください。

## 読書画面

### 文字・レイアウトを変える

横書きと縦書きにはそれぞれ設定があります。**設定 → 読書** から対象の設定を開き、フォント、文字サイズ、余白、行間・字間などを調整します。

EPUBでは書籍のCSSとYomukaの設定の優先関係を選べます。表示がおかしいときは、現在の書籍スタイル設定を記録したうえで、一度だけ別の優先設定に切り替えて比較してください。

### この本だけに設定する（EPUB）

本によって縦横書き、フォント、余白、ルビの見え方を変えたい場合は、EPUBを開いて **決定 → 読書設定 → この本の設定** を開きます。ここで選んだ項目だけがその本に保存され、他の本とホームの **設定 → 読書** にある全体設定は変わりません。

- 各項目の右側に **この本** と表示されたものは、本ごとの設定が有効です。**全体** は全体設定を使っています。
- `現在の設定を保存` は、その時点の読書設定をまとめて本ごとに保存します。
- 元に戻すときは `全体設定を使用` を選びます。本のファイル、しおり、読書位置は消えません。
- 全体を調整したいときは、同じ **読書設定** 内の `全体の読書設定` を開きます。本ごとの設定がある本では、全体を変更してもその本の上書き項目は維持されます。

### 読書設定テスト表示とルビ位置

**設定 → 読書 → 読書設定テスト表示** では、実際のEPUBと同じ読書レイアウトで、縦書き／横書き、ルビ、長文の改行、句読点・括弧、英数字・縦中横、長音、太字を確認できます。左／右で横書き・縦書きを切り替え、**決定** でルビ位置の調整へ入ります。調整中は画面下部の表示に従ってX/Y方向を変更し、**決定** または **戻る** で確定します。

読書中にも **決定 → 表示とレイアウト → ルビ位置調整** から同様に調整できます。本ごとの設定が有効なEPUBでは、その本のルビ位置として保存されます。

### ゴーストが気になるとき

XTCを読んでいる場合は、読書中にメニューを開き **画面を更新** を実行すると、表示を清掃できます。この操作で書籍、しおり、読書位置、設定は消えません。

EPUBで表示がおかしい場合は、まず画面写真と直前の操作を残してください。画像のあるページ、テーマ変更、スリープ復帰の直後かどうかも、調査の助けになります。

## 読書キャッシュ

EPUBはページ表示を速くするため、SDカードに読書キャッシュを作成します。初回に時間がかかることや、書籍の内容・設定変更後に再生成されることがあります。

EPUBを移動・改名した場合や、同じファイル名の更新版へ差し替えた場合も、読書位置、しおり、本ごとの読書設定は引き継がれます。v0.7.1では縦書きのレイアウト基準を更新したため、最初に開く際はキャッシュが自動で再生成されます。

- 問題の切り分けでは、まず対象の本だけのキャッシュ操作を優先してください。
- **設定 → 読書 → 読書キャッシュを消去** のような全体操作は、読書位置や再生成の手間に影響することがあります。実行前に進捗を控え、必要ならSDカードをPCへバックアップしてください。
- キャッシュ生成・更新中は電源断やSDカードの取り外しを避けてください。

書籍ファイルそのものを削除する必要はありません。原因が分からない場合は、キャッシュを何度も消す前に診断レポートを保存してください。

## 本の履歴と読書メーター

ホームの **本の履歴** には、次の2項目があります。

- **読書履歴**: 最近読んだ本を選び、そのまま読書を再開します。読書時間はここには表示しません。
- **読書メーター**: 今日・今週・今月の読書時間、読書した本・読了した本の冊数を確認します。記録がある場合は、直近7日間の棒グラフとよく読んだ本も表示します。

X3では、読書メーターの概要と詳細が別ページです。画面下の **次へ**／**前へ** に従って移動してください。X4では同じ情報を1画面にまとめて表示します。

よく読んだ本には、表示上 `0分` になる本は載りません。短時間でも `1分` 以上の記録がある本は表示されます。

## 日本語フォント

Yomuka v0.6.0では、対応フォントをSDカードから追加して、横書き・縦書きの読書フォントとして選べます。PCから導入する方法、Wi-Fiでのダウンロード、対応フォント、注意事項は「[日本語フォントの導入](./cjk-fonts.md)」を参照してください。

フォント一覧に追加したフォントが出てこない場合は、SDカードの配置を確認して端末を再起動してください。文字が□になる場合は、より収録文字の多いフォントへ切り替えてください。

## 診断レポートを保存する

不具合の再現後、**設定 → 本体 → 診断** から診断情報を保存できます。レポートはSDカードの `/.crosspoint/diagnostics/` に保存されます。

レポートにはファームウェア・端末・空きメモリ・SDカード・読書キャッシュ・直近ログなど、原因調査に必要な状態が入ります。書籍本文や画像を送る必要はありませんが、共有前にファイル名やログに含まれる情報を確認してください。

### Issue #26の調査に協力する場合

購入書籍を開く際のメモリエラーについて調査中です。再現する場合は、書籍ファイルを公開せずに、次をIssueへ添えてください。

1. X3/X4とファームウェアのバージョン
2. 発生画面の写真
3. 発生ページが画像ページか、画像の前後か
4. 保存した診断レポート
5. 書籍の入手元と、分かる範囲の形式・画像サイズ

初期化、SDカードの全消去、購入書籍のアップロードは案内があるまで行わないでください。

## ファームウェア更新

配布物と機種（X3/X4）が一致することを確認してから更新してください。更新前には、SDカードの書籍・設定をPCなどにバックアップし、十分に充電した状態で作業します。

更新中に電源を切ったりSDカードを抜いたりしないでください。更新後に表示や読書キャッシュに違和感がある場合は、まず再起動し、それでも続く場合は診断レポートと画面写真を添えて報告してください。
