## CrossPoint Yomuka v0.8.3

> CrossPoint Yomuka は CrossPoint Reader / CrossPoint JP を基にした非公式コミュニティフォークです。

### 変更の出所

今回の変更には、CrossPoint Reader、CrossPoint JP、reader-mod、FreeInk SDKからの新たなPR・コミットの取り込みはありません。縦書きの変更は[Issue #43](https://github.com/ponto1216-ai/crosspoint-jp/issues/43)の報告と検証を受けたYomuka独自の調整です。v0.8.2で取り込んだ上流修正は[v0.8.2のリリースノート](https://github.com/ponto1216-ai/crosspoint-jp/releases/tag/yomuka-v0.8.2)に記載しています。

### 縦書きの表示

- 「…」を本文１文字分の高さで扱い、後続文字が本文領域からはみ出さないようにしました。BIZ UD系を含むフォントでの位置も調整しました。
- 行末の小書き仮名、句読点、閉じ鍵括弧の配置と、「。」の前後の間隔を調整しました。
- 「――」の間隔を調整し、Zen Maru Gothic用SDフォントに「―」の表示に必要な文字を追加しました。
- 半角カタカナだけの段落を縦書きでも1文字ずつ配置し、行頭位置を修正しました。
- 空段落の直後に続く本文の一行目インデントが失われる問題を修正しました。
- Noto系・BIZ UD系などのフォント差を踏まえ、縦書きの「〜」、英数字・記号の行頭位置、3桁の縦中横の高さを調整しました。
- 縦書きで、数字・ダッシュ・省略記号が続く箇所の向きや間隔を整えました。
- 縦書きで日本語と英文が混じる行の間隔を、フォントに合わせて調整しました。

### 設定・フォント

- 読書設定のテスト表示で例文を切り替えられるようにしました。横書きでは英文も確認できます。
- ツールメニューの項目を整理し、表示診断の名前を通常の診断と区別しやすくしました。
- SDフォントの更新判定を改善しました。ファイルサイズが同じ更新も識別でき、更新後の表示キャッシュを作り直します。更新版は[SDフォント配布ページ](https://github.com/ponto1216-ai/crosspoint-jp/releases/tag/sd-fonts)から入手できます。端末で「アップデート」と表示されるフォントは更新してください。SDカードへZIPを展開する場合は、カード直下に `/.fonts/<フォント名>/` ができることを確認してください。
- 小書きカタカナを横書きでも和文の1文字として扱い、長い文字列の不自然な折り返しを改善しました。
- 日本語SDフォント5種で、元フォントにある括弧付き漢字・単位記号（「㈱」「㊙」「㎝」など）を追加しました。Noto系とBIZ UD系には小書きカタカナ「ㇰ」～「ㇿ」も追加し、Noto系には「𠮷」を追加しました。Zen Maru Gothicの元フォントにはこれら小書きカタカナと「𠮷」の字形がないため、その文字は今回の追加対象外です。
- Zen Maru Gothicに元字形がない「～」（全角チルダ）は、同じフォントの「〜」（波ダッシュ）の字形で表示します。

### X3の電池診断

- 通常の残量確認と同時にBQ27220のEDV2状態を観測し、状態変化とSOCの急変を時刻・有効な読取値とともに診断ログへ記録します。ゲージ設定や容量補正、電源制御は変更していません。
- [Issue #40](https://github.com/ponto1216-ai/crosspoint-jp/issues/40)の30%→7%は原因未確定です。既存レポートでは急落を検出した時点のEDV2はONですが、ONになった瞬間は記録されていません。今回の診断追加は原因調査用であり、急落の修正ではありません。

### 確認範囲と制限

- X3と通常X4で縦書き表示、読書設定テスト表示、メニュー、フォント更新表示についてユーザーによる実機確認を行いました。X3では新しい電池診断ログが出ることも確認しました。残量急落の再現試験は行っていません。
- 追加文字の縦書き・横書き表示と、小書きカタカナの横書き改行は、検証用EPUBでユーザー確認済みです。確認に使った端末種別・全サイズの網羅確認までは記録していません。
- 半角カタカナだけの段落の行頭位置修正は、ホストテストと報告者の画面で確認済みです。確認に使った端末種別・全サイズの網羅確認までは記録していません。
- Zen Maru Gothicの「～」表示は、生成したフォントの字形データと報告者の画面で確認済みです。全サイズの実機確認までは記録していません。
- 下線付き段落の後に空段落を挟む場合の字下げ修正は、報告者の画面で確認済みです。
- 縦書きの英数字・記号の位置と数字／ダッシュの並びは、報告者の画面でNoto系、BIZ UD系、Zen Maru Gothicの表示を確認しました。すべてのサイズ・書籍での確認ではありません。
- 日本語と英文が混じる行の間隔と読書メニュー名は、事前確認版を使ったユーザーの画面で確認済みです。確認に使った端末種別・全サイズの網羅確認までは記録していません。
- X4 Classicはビルド確認のみのExperimental版です。通常X4用ファームウェアをX4 Classicへ使用しないでください。
- Zen Maru Gothicは収録漢字・記号がほかの日本語フォントより少ないため、文字によっては代替表示になります。

### 更新方法

1. 公開されたv0.8.3の `firmware.bin` をSDカードへ置きます。
2. **設定 → 管理 → SDカードファームウェア更新**を実行します。
3. 更新中は電源を切ったりSDカードを抜いたりしないでください。

通常のSD更新には `firmware.bin` を使用します。`bootloader.bin` と `partitions.bin` は初回書き込み・復旧用です。
