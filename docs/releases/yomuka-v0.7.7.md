## CrossPoint Yomuka v0.7.7

> CrossPoint Yomuka は CrossPoint Reader / CrossPoint JP を基にした非公式コミュニティフォークです。

### 主な変更

- X3に「傾きセンサー診断」を追加しました。
  - センサーの検出状態、左右の反応、角速度、ピーク値、判定基準への到達状況を確認できます。
  - 詳細画面でQMI8658の生値、I2Cアドレス、判定軸、閾値、読み取りエラーを確認できます。
  - 診断レポートを `/.crosspoint/diagnostics/` に保存できます。
  - X3だけに表示され、X4には表示されません。
- X3の傾きページ送りをFreeInk SDKのIMU処理へ移行しました。
  - QMI8658の0x6A／0x6Bを検出し、スリープと復帰をSDK側の処理へ統一しました。
  - ページ送り判定はCrossPoint 1.6.5系と同じ角速度基準を使用します。
  - 傾きページ送りのOFF／普通／上下反転設定は、再起動・スリープ復帰後も保持されます。
- 画面の向きを縦、上下逆、右側が上、左側が上から選べるようにしました。
  - 「読書画面に合わせる」を選ぶと、ホームや設定などのUIが本の表示方向に追従します。
  - ホーム、ファイル一覧、設定、ネットワーク、キーボード、青空文庫、診断、保守画面、読書設定、章一覧などを横向き表示へ対応しました。
  - X3/X4の物理ボタンに合わせて、方向別のボタン案内と増減操作を調整しました。
- ホーム画面の読書情報を改善しました。
  - LyraとExtendedに読書進捗バーとしおり表示を追加しました。
  - 横向き時の表紙、タイトル、メニュー、ボタン案内の配置を調整しました。
- 読書履歴を改善しました。
  - 履歴画面の初回表示とスリープ復帰後の読み込みを高速化しました。
  - 個別選択による削除と一括削除を追加しました。
- EPUBの表示とメモリ使用を改善しました。
  - 長い縦書き英字の再表示を高速化し、行端の重なりと欠字を修正しました。
  - ルビと圏点が同じ本文に付く場合の配置を修正しました。
  - 章レイアウト前に不要なフォントキャッシュを解放し、ZIP読み込みと表紙縮小処理の一時メモリを削減しました。
  - HTMLの `hidden` 属性を非表示として扱います。
- WebUIのファイル操作を安全化しました。
  - アップロード、ダウンロード、移動、名前変更、削除、フォルダ作成で共通のパス検証を行います。
- 設定画面を「表示」「読書」「操作」「本体」「管理」に整理しました。
- 開発用のYomukaデスクトップシミュレーターと、主要画面のレイアウト取得手順を追加しました。
- X3のバッテリー残量急落を調査する診断ログを追加しました。[Issue #40](https://github.com/ponto1216-ai/crosspoint-jp/issues/40)
  - 表示値は補正せず、急変時のSOC、電圧、電流、残容量、満充電容量を記録します。
  - 原因は確定しておらず、実測ログを継続して収集します。
- X4がスリープ中もバッテリー保持ラッチを有効にしたままになり、電力を消費する問題を修正しました。
  - フルパワーオフ時にX4のGPIO13を解放し、電源を確実に停止します。
  - 修正前は一晩で72～96mV低下しましたが、修正版では複数回の確認で−2～+10mVの範囲に収まりました。
  - X4の残量表示は電圧から10%単位で推定するため、境界付近では復帰直後に表示が変動する場合があります。

### 上流・派生プロジェクトからの取り込み

次の項目はYomuka独自の新規実装ではなく、CrossPoint本家、FreeInk SDK、派生プロジェクトの修正を確認し、Yomukaの既存機能へ合わせて選択的に取り込んだものです。

- **[FreeInk SDK PR #99](https://github.com/Free-Ink/freeink-sdk/pull/99)の取り込み**: X3のQMI8658を約117 Hzで読み取り、誤ったBIG_ENDIAN指定を外す修正を含むSDK revision `bc31e96`へ更新しました。YomukaではSDKの `Imu` 経由へ移行し、0x6A／0x6B検出とスリープ・復帰を維持しています。
- **CrossPoint本家 [#3353](https://github.com/crosspoint-reader/crosspoint-reader/pull/3353) の取り込み**: WebUIの利用者入力パス検証を、Yomuka独自のアップロード、移動、名前変更、削除、フォルダ作成を維持した形で移植しました。
- **CrossPoint本家 [#3390](https://github.com/crosspoint-reader/crosspoint-reader/pull/3390) の取り込み**: HTMLの `hidden` 属性を非表示として扱う修正を移植しました。
- **CrossPoint本家 [#3527](https://github.com/crosspoint-reader/crosspoint-reader/pull/3527) の取り込み**: EPUB章レイアウト前にフォントキャッシュを解放する修正を、YomukaのSDフォント対策と競合しない形で移植しました。
- **CrossPoint JP [#138](https://github.com/zrn-ns/crosspoint-jp/pull/138) の取り込み・拡張**: Landscape UIの共通レイアウトと各画面対応を基に、Yomukaのテーマ、青空文庫、診断・保守画面、読書補助画面へ合わせて調整しました。さらに「読書画面に合わせる」、X3/X4と画面方向別のボタン案内、横向きホームの進捗・しおり表示を追加しています。
- **CrossPoint JP [#150](https://github.com/zrn-ns/crosspoint-jp/pull/150) の取り込み・拡張**: ホーム画面の読書進捗表示を取り込み、YomukaのLyra／Extendedテーマ、しおり表示、横向きレイアウトへ合わせて調整しました。
- **crosspoint-reader-modを参考にした選択移植**: 長い縦書き英字の再表示、ZIP読み込み、表紙縮小時の一時メモリ使用を見直しました。Yomukaの日本語組版、SDフォント、既存キャッシュ処理を残し、必要な部分だけを取り込んでいます。

X3傾きセンサー診断、設定メニュー整理、読書履歴削除、X3バッテリー診断、X4電源ラッチ修正はYomuka側の実装です。

### 更新時の注意

- 通常の更新では、書籍、設定、読書履歴、しおり、SDカードフォントを削除する必要はありません。
- 初回起動後、画面の向きは従来の縦表示を維持します。横向き表示は **設定 → 表示 → UI方向** から選択できます。
- X3の傾き動作を確認する場合は **設定 → 管理 → 傾きセンサー診断** を使用してください。
- X3のバッテリー残量が大きく変化した場合は、ログが上書きされる前に **設定 → 管理 → 診断 → レポートを保存** を実行してください。
- EPUB表示用キャッシュに問題が見られる場合は、対象書籍の読書メニューからキャッシュを削除して再生成してください。

### 更新方法

1. v0.7.7リリースから `firmware.bin` をダウンロードします。
2. 更新前に書籍と設定をバックアップします。
3. `firmware.bin` を名前を変えずにSDカードへ置き、端末で **設定 → 管理 → SDカードファームウェア更新** を実行します。
4. 通常起動できない場合は、起動時に電源と側面キーを同時に押してリカバリーモードを開き、SDカード上の `firmware.bin` を選択します。
5. 更新中は電源を切ったり、SDカードを抜いたりしません。

`bootloader.bin` と `partitions.bin` は初回書き込み・復旧用、`SHA256SUMS.txt` は配布物の検証用です。通常のSDカード更新では `firmware.bin` を使用します。

詳しい操作は [ユーザーマニュアル](../manual-ja.md)、開発・実機確認の状況は [v0.7.7変更範囲監査](../development/v0.7.7-release-audit-ja.md) を参照してください。
