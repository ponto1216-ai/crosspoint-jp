## CrossPoint Yomuka v0.7.0

> CrossPoint Yomuka は CrossPoint Reader / CrossPoint JP を基にした非公式コミュニティフォークです。

### 主な変更

- 多数のEPUBがあるフォルダを開く際の処理を改善しました。
  - 読書状況・キャッシュ状況の一覧用インデックスを保存し、フォルダを開くたびに各EPUBを確認する処理を減らします。
  - フォルダ内の追加・削除・更新は自動で反映されます。
- ホーム画面の「読書履歴」を追加・拡張しました。
  - 「本の履歴」では最近開いた本と読書キャッシュの有無を確認できます。
  - 「読書メーター」では合計読書時間、読書した本、よく読んだ本を確認できます。
  - X3では時計情報を使い、今日・今週・今月の読書時間と直近7日間のグラフも表示します。X4は電源を完全に切ると時計情報を保持しないため、再起動後は日別・週別・月別の集計とグラフの代わりに、累計・冊数・よく読んだ本を表示します。
- XTCファイルリーダーに読書進捗バーを追加しました。表示位置（上／下）と表示のオン／オフを設定できます。
- 縦書きEPUBで丸数字などの囲み英数字が正しい1文字分の領域を使って表示されるよう修正しました。
- 縦書きEPUBの本文中画像が前後の文字と重なって表示されることがある問題を修正しました。
- 小さなPNG画像を含むEPUBで、メモリの連続領域不足により画像が表示されないことがある問題を修正しました。PNGは読み込み時にBMPキャッシュへ変換して表示します。

### 更新時の注意

縦書きのページ配置を更新しています。v0.7.0へ更新後、EPUBを初めて開く際に読書キャッシュを自動で再生成します。再生成中は最初の表示に時間がかかることがありますが、読書位置・本ごとの設定・読書履歴は保持されます。

### 更新方法

1. [v0.7.0 リリース](https://github.com/ponto1216-ai/crosspoint-jp/releases/tag/yomuka-v0.7.0) から `firmware.bin` をダウンロードします。
2. 更新前に書籍、設定、SDフォントをバックアップします。
3. `firmware.bin` を名前を変えずにSDカードへ置き、端末で **設定 → 本体 → SDカードファームウェア更新** を実行します。
4. 更新中は電源を切ったり、SDカードを抜いたりしません。

`bootloader.bin` と `partitions.bin` は初回書き込み・復旧用、`SHA256SUMS.txt` はダウンロードした配布物の検証用です。通常のSDカード更新では `firmware.bin` を使用します。

詳しい操作は [基本操作・設定・不具合の確認](https://github.com/ponto1216-ai/crosspoint-jp/blob/main/docs/basic-operations-ja.md)、フォント導入は [日本語フォントの導入](https://github.com/ponto1216-ai/crosspoint-jp/blob/main/docs/cjk-fonts.md) を参照してください。
