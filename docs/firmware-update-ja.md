# ファームウェアの導入と更新

[マニュアルの目次](manual-ja.md)

## 方法を選ぶ

| 現在の状態 | 方法 |
|---|---|
| Yomukaを初めて入れる | PCのWeb Flasherから導入 |
| Yomukaが動作しSD更新メニューを開ける | SDカードから更新 |
| 起動不能・SD更新を開けない | 発生画面を記録し、配布版の説明と下の復旧案内を確認 |

X3/X4は共通ファームウェアです。[Releases](https://github.com/ponto1216-ai/crosspoint-jp/releases)で導入する版と既知の制限を確認し、十分に充電し、SDカードの書籍・設定・フォントをバックアップしてください。

## 初回導入（PC）

1. [Yomuka Web Flasher](https://ponto1216-ai.github.io/crosspoint-jp/) をPCのChromeまたはEdgeで開きます。
2. **安定版 (Stable)** を明示的に選び、表示された版を確認します。開発版と取り違えないでください。
3. データ通信できるUSB-Cケーブルで端末をPCにつなぎます。
4. **インストール** を押し、端末のシリアルポートを選びます。画面の案内と消去の確認を読んで進めます。
5. 完了までケーブルを抜かずに待ちます。起動後は[はじめて使う](getting-started-ja.md)へ進みます。

初回書き込みでは端末内の既存ファームウェアやデータが消去されます。端末が候補に出ない場合はケーブルとUSBポートを確認し、解決しない場合は端末・表示内容を添えて報告してください。

## SDカードから更新

1. 使用するリリースから **`firmware.bin`** をダウンロードします。
2. 名前を変えずにSDカードへコピーします。見つけやすいようカード直下に置けます。
3. PCから安全に取り外し、端末へ戻します。
4. **設定 → 本体 → SDカードファームウェア更新** を開き、コピーした `firmware.bin` を選びます。
5. ファイルの検査後、確認画面のファイル名を確かめて更新を実行します。
6. 完了すると自動で再起動します。書き込み中は電源を切ったりSDカードを抜いたりしないでください。

| 配布ファイル | 用途 |
|---|---|
| firmware.bin | 通常のSDカード更新 |
| bootloader.bin / partitions.bin | 初回書き込み・復旧用。通常のSD更新で選ばない |
| SHA256SUMS.txt | ダウンロードした配布物の照合用 |

## 更新後の確認

診断画面でバージョンを確認し、1冊開いてフォント、ページ送り、しおり、スリープ・復帰を確認します。レイアウトやキャッシュ形式が変わった版では、初回に読書キャッシュを再生成するため時間がかかる場合があります。

旧版からの移行に固有の注意は、導入する版のリリースノートを参照してください。例として[v0.7.3の更新時の注意](releases/yomuka-v0.7.3.md#更新時の注意)には、キャッシュ再生成と保持される読書データを記載しています。

## 更新が失敗する・起動しない

ファイル名、入手元、表示されたエラーを記録します。無効なファームウェア等のエラーなら、配布ファイルを再取得してコピーし直してください。正常に起動できる場合は[診断レポート](reporting-bugs-ja.md)を保存します。

復旧画面でSDのファイル選択が出る場合も、同じ版の `firmware.bin` を選びます。Web Flasherでの再書き込みは端末内データの消去を伴う場合があります。繰り返し失敗する場合は、[不具合の報告](reporting-bugs-ja.md)へ進んでください。
