# Yomuka ユーザーマニュアル

このマニュアルは、Xteink X3 / X4でYomukaを使うための案内です。目的に合うページを選んでください。

記述の基準: v0.7.3の実装・既存文書（2026-09-10照合）。v0.7.4に向けて構成を整理しています。新しい画面写真と端末での手順再確認は準備中です。

| したいこと | ページ |
|---|---|
| 初めて導入して本を開く | [はじめて使う](getting-started-ja.md) |
| ページをめくる・章やしおりへ移動する | [本を読む](reading-ja.md) |
| 文字・ルビ・余白を調整する／この本だけ変える | [読書の設定](reading-settings-ja.md) |
| 本を探す・書庫へ移す・履歴や読書時間を見る | [本の管理と読書記録](library-ja.md) |
| 日本語フォントを追加する | [フォントの導入](cjk-fonts.md) |
| 画面・ボタン・スリープ・言語を設定する | [本体と操作の設定](device-settings-ja.md) |
| Wi-Fiで本を転送する・青空文庫を使う | [Wi-Fiとファイル転送](wifi-transfer-ja.md) |
| インストール・アップデートする | [ファームウェアの導入と更新](firmware-update-ja.md) |
| 表示や動作の問題を調べる | [困ったとき](troubleshooting-ja.md) |
| 診断レポートやクラッシュ記録を送る | [不具合の報告](reporting-bugs-ja.md) |

版ごとの変更と更新時の注意は[リリース一覧](https://github.com/ponto1216-ai/crosspoint-jp/releases)を参照してください。開発に参加する方は[開発者ガイド](contributing/README.md)へ進んでください。
