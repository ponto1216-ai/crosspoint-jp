# 本を読む

[マニュアルの目次](manual-ja.md)

## 本を開く・ページをめくる

ファイル一覧で本を選んで **決定** を押します。最近読んだ本は **本の履歴 → 読書履歴** から再開できます。ページ送りは画面の案内と設定したボタン割り当てに従ってください。

長押しのページ送り動作は設定により異なります。[本体と操作の設定](device-settings-ja.md)で割り当てを確認できます。

X3では **設定 → 操作 → 傾きでページ送り** を有効にすると、端末を左右へ動かしてページを送れます。ゆっくり角度を変える操作ではなく、一定以上の速さを検出する方式です。反応の確認には[傾きセンサー診断](device-settings-ja.md#x3の傾きセンサー)を使ってください。

同じEPUBを横書き・縦書きで表示した例です。フォント、文字サイズ、行間、ルビ位置は読書設定で変更できます。

## EPUBの読書中メニュー

読書中に **決定** を押します。

| メニュー | できること |
|---|---|
| 読書位置 | 章を選択、しおり一覧、しおりを追加／削除、割合で移動 |
| この本の表示 | フォント、文字サイズ、画面の向き、行間、字下げ、ルビ位置、画像反転の調整 |
| 読書動作 | 自動ページ送り、傾きページ送りの設定 |
| 管理・診断 | この書籍のキャッシュ生成・残りの生成・削除、読書中の診断 |
| 保存・共有 | スクリーンショット、QR表示、SDで読書データを共有 |
| 読書設定 | 本ごとの設定、全体の読書設定 |

しおりを付けるには **読書位置 → しおりを追加／削除** を選びます。同じ場所で再度選ぶと外せます。しおりがある場合に **しおり一覧** が表示されます。

表示設定の優先関係と保存先は[読書の設定](reading-settings-ja.md)を参照してください。TXT・XTC/XTCHでは、EPUBとメニューや利用できる設定が異なります。

EPUBでは、**保存・共有 → SDで読書データを共有** から読書位置・しおり・本固有設定・履歴を受け渡せます。手順は[読書データを共有する](reading-data-sharing-ja.md)を参照してください。

v0.8.1以降では、最初のページを正常に表示できた本だけをスリープ復帰の対象として記録します。最初のページを表示できない本は、スリープ・復帰後に再び開きません。空TXTは「空のファイル」と表示し、その状態からの復帰ではHomeへ戻ります。正常なEPUB・TXT・XTC/XTCHの読書位置保存は引き続き利用できます。

**この本の表示 → 文字サイズ** は、決定で変更状態に入り、左／右で **小／中／大／特大** を選びます。決定または戻るで変更状態を閉じると、本文に戻ったときにその本だけの表示として反映されます。

## 読書キャッシュ

EPUBはページ表示を速くするためSDカードへキャッシュを作ります。初回や内容・レイアウトの変更後は生成に時間がかかることがあります。

**決定 → 管理・診断** では、未生成なら **この書籍の読書キャッシュを生成**、途中まで生成済みなら **この書籍の残りのキャッシュを生成** を選べます。完了済みの本では生成項目は表示されません。生成を中断するときは、画面のボタン案内を確認し、**戻るを約1秒以上、停止するまで長押し**してください。処理の区切りで停止するため、重い章や画像では反応まで時間がかかる場合があります。電源断で止めないでください。

<img src="images/reading/reader-menu-cache-x3.png" alt="X3の読書中メニューで、この書籍の残りのキャッシュを生成する項目を選択した画面" width="360">

初回に本を開いたときは、読み込み高速化キャッシュを生成するか確認される場合があります。**あとで** を選んで先に本文を開き、読書中メニューから後で生成することもできます。

<img src="images/reading/cache-generation-prompt-x3.png" alt="X3で読み込み高速化キャッシュを生成するか確認する画面" width="360">

生成中は章数と進捗を表示します。画面に示されたボタンで中断できます。

**設定 → 管理 → 読書キャッシュを一括生成** では、SDカード内の複数の書籍を続けて処理できます。中断するときは、**戻るを約1秒以上、停止するまで長押し**します。短押しでは中断しません。

大量の書籍や長文・複雑なCSS・画像の多い本では、一括生成に数時間以上かかる場合があります。全書籍の事前生成は必須ではありません。途中で中断し、後で同じ操作を実行すると、有効な生成済みキャッシュを再利用して続きを生成します。読書設定の変更などでキャッシュが無効になった場合は再生成されます。

完了画面では、生成が完了した書籍、途中から再開できる書籍、未生成の書籍の数を確認できます。

<img src="images/reading/all-cache-generation-complete-x3.png" alt="X3の一括キャッシュ生成完了画面。完了、再開可能、未生成の書籍数を表示" width="360">

表示の問題を調べる場合は、先に[診断レポート](reporting-bugs-ja.md)を残してください。その後、必要な場合に対象の本の **この書籍のキャッシュを削除** を使います。本体設定にある全体の消去とは区別してください。書籍ファイルを削除する必要はありません。

読書位置やしおりの保持については[本の管理](library-ja.md)、生成が進まない場合は[困ったとき](troubleshooting-ja.md)を参照してください。
